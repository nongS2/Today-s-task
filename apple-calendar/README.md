# 애플 캘린더 연결하기

```
아이폰 과목 캘린더들 (일정 입력)
   │  iCloud 공개 캘린더 링크들
   ▼
Google Apps Script (Code.gs, 무료 중계)
   ▼
학사일정 사이트 ──▶ 노션 페이지에 embed ──▶ 친구들
```

캘린더 하나가 과목 하나예요. 사이트에는 아이폰에서 정한 **캘린더 이름과 색**이 그대로 나와요.

## 1. 캘린더 공개 링크 복사하기 (아이폰)

> ⚠️ 공개한 캘린더는 링크를 아는 누구나 볼 수 있어요. 공유하고 싶은 캘린더만 공개하세요.

공유할 캘린더마다:
1. 캘린더 앱 → 아래 **캘린더** → 캘린더 옆 ⓘ
2. **공개 캘린더** 켜기 → **링크 공유…** → **복사**
   - `webcal://p…-caldav.icloud.com/published/2/…` 같은 링크예요.
3. 메모 앱 같은 데에 모아두기

## 2. 중계 스크립트 배포 (Google)

1. https://script.google.com → **새 프로젝트**
2. 기본 코드를 지우고 [`Code.gs`](Code.gs) 내용을 붙여넣기
3. `ICS_URLS` 안에 1번에서 모은 링크를 한 줄에 하나씩 붙여넣고 저장
   ```js
   const ICS_URLS = [
     'webcal://p…/published/2/…',   // 영어
     'webcal://p…/published/2/…',   // 국어
   ];
   ```
4. **배포** → **새 배포** → 유형 ⚙️ **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. **배포** → 권한 승인 (“확인되지 않은 앱” 화면이 나오면 *고급* → *이동*)
6. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사

> 나중에 캘린더를 추가·삭제했다면 `ICS_URLS`를 고치고 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영돼요. (URL은 그대로예요)

## 3. 사이트에 연결

`index.html`의 이 줄에 웹 앱 URL을 넣으면 끝이에요.

```js
const ICS_PROXY_URL='';
```

비워두면 예전처럼 구글 시트에서 일정을 읽어요.

## 일정은 지금처럼 쓰면 돼요

- **색과 과목**: 일정이 들어 있는 캘린더로 정해져요.
- **D-day**: 제목으로 자동 분류해요.
  - `수행` → 수행평가
  - `중간고사`·`기말고사` → 정기시험
  - `모의고사` → 모의고사
- **반복 일정**(매주 방과후 등)도 모든 날짜에 표시돼요. 오늘부터 1년 뒤까지만 보여요.
- **여러 날 일정**은 기간 전체에 표시돼요.
- **메모**에 적은 내용은 일정 설명으로 나와요.
- 아이폰에서 고친 내용이 공개 링크에 반영되기까지 몇 분 걸릴 수 있어요.

## 4. 노션에 넣기

1. 노션 페이지에서 `/embed` 입력 → 사이트 주소 붙여넣기
2. 블록 크기를 세로로 넉넉하게 늘리기
3. 오른쪽 위 **공유**에서 친구들을 초대하거나 **웹에 게시**
