# 애플 캘린더 연결하기

```
아이폰 캘린더 (일정 입력)
   │  iCloud 공개 캘린더 링크
   ▼
Google Apps Script (Code.gs, 무료 중계)
   ▼
학사일정 사이트 ──▶ 노션 페이지에 embed ──▶ 친구들
```

## 1. 공유용 캘린더 만들기 (아이폰)

> ⚠️ 공개한 캘린더는 링크를 아는 누구나 볼 수 있어요. 개인 일정이 섞인 캘린더 말고 **새 캘린더**를 따로 만드세요.

1. 캘린더 앱 → 아래 **캘린더** → **캘린더 추가** → 이름: `학사일정` (iCloud 계정에 만들기)
2. `학사일정` 옆 ⓘ → **공개 캘린더** 켜기 → **링크 공유…** → **복사**
   - `webcal://p…-caldav.icloud.com/published/2/…` 같은 링크가 복사돼요.

## 2. 중계 스크립트 배포 (Google)

1. https://script.google.com → **새 프로젝트**
2. 기본 코드를 지우고 [`Code.gs`](Code.gs) 내용을 붙여넣기
3. `ICS_URL`의 따옴표 안에 1번에서 복사한 링크 붙여넣기 → 저장
4. **배포** → **새 배포** → 유형 ⚙️ **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. **배포** → 권한 승인 (“확인되지 않은 앱” 화면이 나오면 *고급* → *이동*)
6. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사

## 3. 사이트에 연결

`index.html`의 이 줄에 웹 앱 URL을 넣으면 끝이에요.

```js
const ICS_PROXY_URL='';
```

비워두면 예전처럼 구글 시트에서 일정을 읽어요.

## 일정 입력 규칙

제목 앞에 `[종류]`를 붙이면 색이 구분돼요.

| 캘린더 제목 | 사이트 표시 |
|---|---|
| `[수행평가] 국어 발표` | 🟠 수행평가 · 국어 발표 |
| `[정기시험] 2학기 기말고사` | 🔴 정기시험 |
| `[모의고사] 11월 모의고사` | 🩷 모의고사 |
| `[과제] 물리 보고서` | 🔵 과제 |
| `[방학] 겨울방학` (여러 날 종일) | 🟢 기간 전체에 표시 |
| `[주요행사] 축제` | 🟣 주요행사 |
| `동아리 모임` (종류 없음) | ⚪ 기타 |

- **메모**에 적은 내용은 일정 설명으로 나와요.
- 여러 날짜에 걸친 일정(방학, 시험 기간)은 달력의 모든 날짜에 표시돼요.
- 반복 일정은 첫 번째 날짜만 표시돼요.
- 아이폰에서 고친 내용이 iCloud 공개 링크에 반영되기까지 몇 분 걸릴 수 있어요.

## 4. 노션에 넣기

1. 노션 페이지에서 `/embed` 입력 → 사이트 주소 붙여넣기
2. 블록 크기를 세로로 넉넉하게 늘리기
3. 오른쪽 위 **공유**에서 친구들을 초대하거나 **웹에 게시**
